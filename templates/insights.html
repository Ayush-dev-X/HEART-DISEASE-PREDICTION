06 · MODEL INSIGHTS

What the Model Evaluation Shows

Key observations from the clinical-only and clinical + genetic Logistic Regression experiments recorded in the notebook.

01 PERFORMANCE

Genetic Inputs Improve Results

Adding genetic and family-history attributes increased test accuracy from 85.87% to 89.13% and F1 score from 86.60% to 89.36% on this split.

02 GENETIC FEATURE SET

Six Additional Inputs

FamilyHistory, rs10757274_Genotype, APOE_Genotype, Lpa_Level, FH_Mutation and Genetic_Risk_Score are added to the 11 clinical variables.

03 PREPROCESSING

Pipeline-based Preparation

Numeric fields use median imputation and StandardScaler; categorical fields use most-frequent imputation and OneHotEncoder with unknown-category handling.

04 TEST SET

Stratified Evaluation

Both variants use the same 80 / 20 stratified split (random state 42), with 734 training records and 184 test records.

About these insights

These metrics describe performance on one held-out split of the supplied dataset. The notebook does not demonstrate external validation on an independent hospital or unseen population. Genetic fields in this dataset are model inputs, not a substitute for laboratory testing or clinical interpretation. CardioSense is an educational decision-support prototype and does not provide a medical diagnosis.
